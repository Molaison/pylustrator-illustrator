# Offline example assets

`1crn.pdb` is the public RCSB PDB entry **1CRN**, crambin, downloaded from
https://files.rcsb.org/download/1CRN.pdb for the molecular-rendering example.
Entry and original experimental references: https://www.rcsb.org/structure/1CRN.
The original PDB header and citation records are preserved.

The workspace's optional example plot uses explicitly labeled illustrative
enzyme-response values. It is not an experimental result.
