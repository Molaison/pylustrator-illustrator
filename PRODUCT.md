# Pylustrator Forge Web

A scientific figure workspace for researchers who need publication composition on a
headless workstation, with reproducible data and structure provenance.

The primary workflow is project → source data → inspect/prepare → plot → compose →
add molecular view → checkpoint → publication export. Existing Matplotlib users can
attach a trusted in-process Figure to a headless native editing session.

The artboard is the primary surface. Data, Structures, and Versions are focused views
within the same project. Raw data never changes silently. AI proposes validated steps;
the researcher previews and applies them. Save, checkpoint, and publication export
are separate actions. Existing desktop editing remains an optional compatibility mode.
